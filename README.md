# NUMBER STAGE

Windows / Mac のブラウザで使える、16:9 のランダム数字抽選アプリです。外部ライブラリやビルドは不要です。アプリ本体はリポジトリ直下の [index.html](index.html) です。

## 機能

- 数字の候補を範囲またはリストで指定し、重複の有無を設定
- スタート・ストップで抽選し、16:9 の画面に数字を表示
- タブで抽選画面と履歴画面を切り替え
- 背景画像、数字のフォント・色・大きさ・位置を設定
- BGM は専用ボタンで再生・停止し、抽選とは独立してリピート
- スタート音は抽選開始時に鳴り、抽選停止時に止まる
- ストップ音は抽選停止時に鳴る
- 3 種類の音量を個別に調整し、読み込んだ音声を解除
- 背景・BGM・スタート音・ストップ音を GitHub に保存し、別端末で自動読込
- 抽選履歴をブラウザに保存し、CSV で書き出し

## 素材を別端末と共有する

1. [GitHub の fine-grained personal access token](https://github.com/settings/personal-access-tokens/new) を作成します。Repository access は `yamadesu46/number` のみ、Repository permissions の **Contents** は **Read and write** にします。
2. アプリの「素材をGitHubで共有」にトークンを入力し、「保存用トークンをセット」を押します。トークンはそのタブのメモリだけに保持し、リポジトリやブラウザの永続保存領域には記録しません。チャットにも貼らないでください。
3. 背景または音声ファイルを選ぶと GitHub に保存されます。ファイル名の横に ☁ が付き、「GitHubに保存しました」と表示されたら完了です。別端末では同じアプリを開くだけで素材を読み込みます。解除は保存用トークンをセットしてから行います。

このリポジトリは公開されています。共有した画像・音声は誰でも閲覧できます。1 ファイルあたり 25 MB までです。対応する音声形式は端末のブラウザによって異なります。トークンはページを開き直すたびに再入力します。

数字の設定、抽選履歴、アップロードしたフォントは端末・ブラウザごとに保存されます。必要な履歴は CSV で保管してください。

## 別の端末で編集する

GitHub の `yamadesu46/number` リポジトリを開き、`index.html` を編集してください。Codex Cloud で続ける場合は、このリポジトリを含むクラウド環境から新しいタスクを始めてください。変更は GitHub にコミットして共有します。

## GitHub Pages

GitHub Pages を有効にしている場合、アプリのURLは https://yamadesu46.github.io/number/ です。未設定なら **Settings → Pages → Deploy from a branch → main / (root)** を選んで保存します。
